# TaskManagerPlus curated pool tag dictionary (#418)
#
# This is a small, hand-curated subset (not the full WDK pooltag.txt, which runs to several
# thousand entries and isn't always redistributable) covering the most common/well-known kernel
# pool tags a home/dev machine is likely to actually see in the #416 "Kernel pool by tag" grid.
# Compiled from public Windows-internals documentation and widely-published pool-leak-diagnosis
# references, on a best-effort basis - treat a match here as a helpful pointer, not a guaranteed-
# authoritative identification (some tags are reused by more than one component in practice).
# A tag with no entry below simply shows no description in the grid - never a guessed one.
#
# Format: one entry per line, "TAG=Description (Component)". Tags are exactly 4 characters,
# spaces significant (the object manager and many drivers pad short tags with trailing spaces).
# Lines starting with # are comments.
